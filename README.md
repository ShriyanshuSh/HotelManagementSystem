# Hotel Management System

Spring Boot REST API project for managing hotel rooms and bookings.

## Technologies Used

- Spring Boot
- Spring Data JPA
- Oracle Database
- Maven

## Modules

Room Management
Booking Management

## APIs

POST /rooms
GET /rooms
GET /rooms/{id}
PUT /rooms/{id}
DELETE /rooms/{id}

POST /bookings
GET /bookings
GET /bookings/{id}
PUT /bookings/{id}
DELETE /bookings/{id}
